# Advance-nuclear-physics-lab-
repository contains a collection of programs developed to digitize, automate, and analyze nuclear physics experiments. The objective is to convert traditional experimental measurements into digital datasets and apply computational methods for faster, reproducible, and more accurate analysis.

The codes cover several important nuclear and radiation physics experiments, including:

Compton Scattering
Geiger–Müller (GM) Counter
Detector Efficiency
Convolution and Signal Analysis
